逻辑门

逻辑门是数字电路的基础，通过红石元件可以实现各种逻辑门。理解逻辑门对于设计复杂电路至关重要。

📚 基本概念

什么是逻辑门？

逻辑门是执行逻辑运算的电路，接收一个或多个输入，产生一个输出。

真值表

真值表列出了所有可能的输入组合及对应的输出：

输入 A输入 B输出
00?
01?
10?
11?

在红石中的应用

  • 0 = 无信号（OFF）
  • 1 = 有信号（ON）

🚫 NOT 门（非门）

逻辑运算

反转输入信号

真值表

输入输出
01
10

红石实现

方案一：红石火把

输入 → 方块 → 红石火把 → 输出

特性

  • 最简单的 NOT 门
  • 1 红石刻延时
  • 体积：1×2×2

方案二：红石火把塔

输入 → 方块 → 火把 → 方块 → 火把 → 输出
（双重反相）

应用

  • 信号反相
  • 控制反向逻辑
  • 构建其他逻辑门

∧ AND 门（与门）

逻辑运算

所有输入都为 1 时，输出才为 1

真值表

AB输出
000
010
100
111

红石实现

方案一：串联红石火把

输入A → 方块 → 火把 → 方块 ← 输入B
                             ↓
                          红石火把 → 输出

方案二：双输入中继器

输入A → 中继器 → 方块
输入B →        ↗
               方块 → 输出

方案三：串联电路

信号源 → 开关A → 开关B → 输出
两个开关都打开才有信号

应用

  • 多条件判断
  • 安全系统（需要多个条件）
  • 复杂电路的组合条件

∨ OR 门（或门）

逻辑运算

任一输入为 1，输出就为 1

真值表

AB输出
000
011
101
111

红石实现

方案一：简单并联

输入A ─┐
       ├→ 输出
输入B ─┘

方案二：使用中继器

输入A → 中继器 ─┐
                ├→ 方块 → 输出
输入B → 中继器 ─┘

应用

  • 多个触发源
  • 备用输入
  • 检测多个条件中的任一个

⊕ XOR 门（异或门）

逻辑运算

两个输入不同时，输出为 1

真值表

AB输出
000
011
101
110

红石实现

方案一：红石火把XOR

     方块A          方块B
       ↓              ↓
输入A → 火把 → 线 ← 火把 ← 输入B
              ↓
            输出

方案二：比较器XOR

输入A → 比较器（减法）→ 输出
输入B →    ↓侧面

应用

  • 双控开关
  • 奇偶性检测
  • 加法器的实现

↓ NOR 门（或非门）

逻辑运算

所有输入都为 0 时，输出才为 1 （OR 的反向）

真值表

AB输出
001
010
100
110

红石实现

OR + NOT

输入A ─┐
       ├→ 方块 → 红石火把 → 输出
输入B ─┘

应用

  • 检测所有输入都关闭
  • 警报系统
  • 复杂逻辑的构建块

↑ NAND 门（与非门）

逻辑运算

任一输入为 0，输出就为 1 （AND 的反向）

真值表

AB输出
001
011
101
110

红石实现

方案一：简单NAND

输入A → 方块 ← 输入B
         ↓
      红石火把 → 输出

方案二：两个NOT串联

输入A ─┐
       ├→ AND门 → NOT门 → 输出
输入B ─┘

应用

  • 万能门（可构建任何逻辑）
  • 锁存器的实现
  • 复杂电路简化

⊙ XNOR 门（同或门）

逻辑运算

两个输入相同时，输出为 1 （XOR 的反向）

真值表

AB输出
001
010
100
111

红石实现

XOR + NOT

XOR门的输出 → NOT门 → 输出

应用

  • 相等性检测
  • 同步检测
  • 复杂条件判断

🔧 组合逻辑

多输入逻辑门

3输入 AND 门

A AND B → 中间结果 AND C → 输出

3输入 OR 门

A OR B → 中间结果 OR C → 输出

优先级编码器

根据优先级选择输出：

高优先级输入 → 如果有信号则输出
             ↓ 否则
中优先级输入 → 如果有信号则输出
             ↓ 否则
低优先级输入 → 输出

多路选择器

根据选择信号选择不同的输入：

选择信号 = 0 → 输出 = 输入A
选择信号 = 1 → 输出 = 输入B

🎯 实践项目

项目一：密码锁

使用逻辑门设计一个需要特定输入组合的门：

要求：只有当 A=1, B=0, C=1 时才打开
解决：(A AND (NOT B) AND C) → 门

项目二：多人投票系统

设计一个3人投票系统，多数同意才通过：

(A AND B) OR (A AND C) OR (B AND C) → 通过

项目三：双控开关

两个开关控制一个灯，任一开关变化都会切换灯的状态：

开关A XOR 开关B → 灯

💡 优化技巧

减少延时

  • 使用直接连接代替火把
  • 并联结构优于串联
  • 避免不必要的反相

节省空间

  • 利用3D空间
  • 重用方块
  • 紧凑布局

提高可读性

  • 标记输入输出
  • 统一走线方向
  • 模块化设计
