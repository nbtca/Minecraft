时序电路

时序电路是包含时间元素的红石电路，主要包括时钟、延时器和脉冲发生器等。

⏰ 时钟电路

时钟电路产生周期性的信号，是自动化系统的核心。

侦测器时钟

最快时钟

侦测器 ⇄ 侦测器
两个侦测器面对面
  • 周期：2 红石刻（0.2秒）
  • 特点：最快的时钟
  • 用途：高速机械

可控侦测器时钟 添加活塞可以控制开关。

中继器时钟

2中继器时钟

中继器 → 中继器
   ↑__________|
  • 周期：可调（最短4红石刻）
  • 特点：简单稳定
  • 延时：2个中继器的延时之和

多中继器环形时钟

中继器 → 中继器 → 中继器 → ...
   ↑__________________________|
  • 周期：所有中继器延时之和
  • 特点：周期可调范围大

比较器时钟

比较器循环时钟

比较器 → 中继器 → 比较器
   ↑__________________|
  • 周期：稳定可调
  • 特点：准确度高

漏斗时钟

物品循环时钟

漏斗 ⇄ 漏斗
放入物品循环传输
  • 周期：较长（秒级）
  • 特点：精确、可调节
  • 用途：长周期定时

⏱️ 延时电路

延时电路将输入信号延迟一段时间后输出。

中继器延时

基本延时

输入 → 中继器 → 中继器 → ... → 输出
  • 每个中继器：1-4 红石刻
  • 总延时：所有中继器之和
  • 最小：1 红石刻
  • 实用范围：1-64 红石刻

比较器延时

精确延时

输入 → 比较器 → 比较器 → ... → 输出
  • 比较器延时：1 游戏刻（0.5红石刻）
  • 更精确的控制

长延时电路

漏斗延时器

输入 → 漏斗链 → 比较器检测 → 输出
  • 范围：秒到分钟
  • 精确可调
  • 适合长时间延时

投掷器延时 类似漏斗延时，使用投掷器传递物品。

💫 脉冲发生器

将持续信号转换为短脉冲。

边缘检测

上升沿检测

输入 → 方块 → 红石粉 → 输出
    ↘ 中继器 → 红石火把 ↗
  • 检测信号从 0 到 1 的变化
  • 输出1个红石刻脉冲

下降沿检测

输入 → NOT → 边缘检测 → 输出
  • 检测信号从 1 到 0 的变化

单稳态电路

按钮脉冲生成

按钮 → 中继器 → 输出
    ↘ 红石粉 → 火把 → 中继器 ↗
  • 任意长度输入 → 固定长度输出
  • 脉冲宽度可调

活塞脉冲

瞬时脉冲

输入 → 活塞 → 红石块 → 输出
  • 极短脉冲
  • 1 游戏刻或更短

🔄 分频器

将时钟频率降低。

2分频

T触发器

输入时钟 → 活塞 → 红石块来回移动
  • 输出频率 = 输入频率 / 2

N分频

计数器分频 使用计数器实现任意比例分频。

🎯 实用电路

脉冲延长器

短脉冲 → 延长 → 长脉冲

用于：

  • 按钮信号延长
  • 确保触发完成

脉冲缩短器

长脉冲 → 缩短 → 短脉冲

用于：

  • 防止重复触发
  • 快速操作

单次触发

输入 → 检测 → 输出一次

确保只触发一次，防止连续触发。

💡 设计技巧

选择时钟类型

  • 高速 → 侦测器时钟
  • 中速 → 中继器时钟
  • 低速 → 漏斗时钟
  • 精确 → 比较器时钟

稳定性考虑

  • 避免过快的时钟导致卡顿
  • 考虑区块加载影响
  • 测试长时间运行

可控性

  • 添加开关控制
  • 可调节周期
  • 易于维护

🎓 实践项目

  1. 闪烁灯 - 制作周期性闪烁的红石灯
  2. 自动农场 - 使用时钟控制自动收割
  3. 音乐播放器 - 用时钟触发音符盒
  4. 定时门 - 自动开关的门

提示

时序电路是自动化的基础，理解延时和周期对于设计复杂系统至关重要！
