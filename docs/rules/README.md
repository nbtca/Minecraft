# 服务器规则

为了营造良好的游戏环境，请所有玩家遵守以下规则。

## 📜 基本规则

### 尊重他人

1. **友善交流** - 禁止辱骂、歧视性言论
2. **尊重财产** - 不破坏他人建筑
3. **公平游戏** - 不使用作弊手段
4. **团队协作** - 互相帮助，共同进步

### 游戏行为

1. **合理建设** - 参考 [建设规范](/rules/building.md)
2. **资源获取** - 不过度开采公共资源
3. **设备使用** - 合理使用公共设施
4. **性能考虑** - 避免造成服务器卡顿

## 🏗️ 建设规范

详见 [建设规范](/rules/building.md)

### 基本要求

- 在指定区域建设
- 保持周围环境整洁
- 大型建筑需报备
- 注意性能影响

### 生电装置

- 添加开关控制
- 标注用途和作者
- 避免过度密集
- 及时维护清理

## 🤝 社区准则

详见 [社区准则](/rules/community.md)

### 互助友好

- 乐于分享知识
- 帮助新手玩家
- 积极参与活动
- 维护社区氛围

### 争议处理

- 理性沟通
- 寻求管理员协助
- 遵从仲裁结果

## ⚠️ 违规处理

### 处罚等级

1. **警告** - 首次轻微违规
2. **临时封禁** - 严重或重复违规
3. **永久封禁** - 恶意破坏或作弊

### 申诉途径

如对处罚有异议，可向管理员申诉。

## 📞 联系管理

遇到问题或需要帮助时：

- 游戏内私信管理员
- 加入服务器交流群
- 在论坛发帖求助

不知者不罪，但请务必在加入服务器后及时阅读规则！
