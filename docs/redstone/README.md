## 🔴 红石系统概述

### 红石是什么？

红石是 Minecraft 中的一种矿物，可以被制作成红石粉和各种红石元件。红石粉可以传输信号，类似于现实世界的电线。

### 核心概念

1. **信号** - 红石信号有 0-15 级强度
2. **传输** - 信号通过红石粉传输，每格衰减 1 级
3. **充能** - 方块可以被充能，从而激活相邻元件
4. **逻辑** - 通过组合元件实现逻辑运算

## 🧰 基本元件分类

### 信号源

产生红石信号的元件：
- 拉杆、按钮、压力板
- 侦测器、绊线钩
- 阳光传感器、重量压力板

### 传输元件

传递和处理信号的元件：
- 红石粉、红石火把
- 中继器、比较器

### 输出元件

接收信号并执行动作的元件：
- 活塞、红石灯
- 发射器、投掷器
- 门、活板门

### 特殊元件

具有独特功能的元件：
- 红石块（移动信号源）
- 粘液块（粘附方块）
- 侦测器（检测更新）

## 💡 实用技巧

### 调试技巧

遇到电路不工作时的检查清单：

1. **检查信号源** - 确认信号源正常工作
2. **检查连接** - 确保红石粉正确连接
3. **检查距离** - 信号传输不超过 15 格
4. **检查充能** - 确认方块正确充能
5. **检查更新** - 某些电路需要方块更新

### 设计建议

制作红石电路时的最佳实践：

- **从简单开始** - 先构建小模块，再组合
- **保持整洁** - 规划好线路走向
- **添加标记** - 用方块或告示牌标记功能
- **测试充分** - 多次测试确保稳定性
- **考虑性能** - 避免过度复杂的电路

## 🎨 设计模式

### 垂直信号传输

在多层建筑中传输信号的方法：

- **红石火把塔** - 交替的火把和方块
- **侦测器-活塞链** - 快速垂直传输
- **红石块-活塞电梯** - 移动红石块

### 水平信号传输

长距离传输信号：

- **中继器链** - 每 15 格放置中继器
- **蓝冰道** - 使用蓝冰快速传输物品信号
- **命令方块链** - 创造模式下的瞬时传输

### 信号分配

将一个信号分配到多个输出：

- **T 型分叉** - 简单的信号分叉
- **比较器复制** - 保持信号强度
- **独立线路** - 避免互相干扰
